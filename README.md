# A Systematic Review of Provenance for Machine Learning Experiments: A New Taxonomy and Comparative Analysis

## Description

This repository contains the review protocol, search documentation, data-extraction form, and original bibliographic search exports supporting the systematic literature review of structured provenance for machine-learning experiments.

The review reports 43 primary reports, consolidated into 29 provenance system families. The five-axis taxonomy and the comparative results are presented in the accompanying article.

The primary database search was closed on 16 February 2026. The publicly shared material focuses on the study protocol and bibliographic retrieval records; it does not include individual screening decisions or completed extraction records.
